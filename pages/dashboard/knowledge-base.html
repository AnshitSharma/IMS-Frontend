Start here

BDC Inventory is where we record every piece of server hardware we own: what it is, where it is, and which server it is in.

Almost everything you do here is one of three jobs.

Parts

Record hardware when it arrives, find it later, and report it when it breaks.

Servers

Put parts together into a server. The system checks that they fit.

Requests

Ask for something you can't do yourself. An admin approves it and the system does it.

Signing in

  • Type your username and password, then click Sign in. If you have a company Microsoft account, you can click Continue with Microsoft instead.
  • Tick Keep me signed in for 30 days only on your own computer. On a shared computer, leave it unticked and sign out when you leave.
  • Forgot your password? Click Forgot? next to the password box and enter your work email. You will get an email with a link to set a new one.

Changing your password

Click the arrow next to your name at the top right, then Change password. A new password needs at least 8 characters, with one capital letter, one number and one symbol such as # or !. Once it is changed you are signed out, so sign in again with the new one.

If you're not allowed to do something

Everyone can look at everything. What you can change depends on your role. When you can't make a change yourself, the button for it usually still works: you fill in the same form, and it is sent to an admin as a Request. Once they approve it, the system makes the change for you.

For example, you click Add RAM, fill in the form and save. Instead of the RAM being added, you see "Request TKT-20261008-0012 submitted. The component will be added once an admin approves it." The RAM shows up in the list after approval.

Getting around

Every page has the same top bar and the same menu on the left.

On a phone, tap the button at the top left to open the menu.

The Dashboard

The Dashboard is the home page. Click BDC Inventory at the top left to get back to it from anywhere.

  • Needs your attention lists what to act on today. Each line has a button that takes you straight there.
  • Parts shows how much spare hardware we have, by part type.
  • Server builds counts the servers at each stage, and Recent activity shows the latest changes.

Find a part

Each kind of part has its own page under Inventory in the menu: CPUs, RAM, Storage and so on. Not sure what a part is? See Words you'll see.

Click the server name in the Installed in column to open that server.

Example

You need a free 32 GB RAM stick at CtrlS Noida. Open RAM, click the Available tab, set Location to CtrlS Noida, and type 32GB in the search box.

Export CSV downloads exactly what is on screen, filters included, as a file you can open in Excel.

Add new parts

Add every unit to stock when it arrives, before it goes into a server.

1

Open the page for that part, for example RAM, and click Add RAM.

2

Choose the model. Fill the boxes in order, because each choice narrows the next one. For RAM that is memory type, then capacity, then form factor, then the exact model.

3

Type the serial number from the label on the part. It is required for Storage and SFP modules. For other parts, leave it blank only if the label is missing or unreadable.

4

Choose the Site. This is required. You can also say where it sits in Shelf / bin, for example Shelf B3, Bin 12.

5

Click Add RAM. Write the asset tag it gives you on a label and stick it on the part.

Leave Status on Available for a new part. After saving you see a message like this. The code in it is the part's asset tag, our own ID for that one unit:

To find that unit again later, type its asset tag into the search box.

The model isn't in the list?

Don't pick one that looks close. Ask an admin to add the right model first. A wrong model means the fit checks will be wrong when the part goes into a server.

Adding many at once

  • Many of the same model: set Quantity, for example 32, and paste the serial numbers one per line.
  • Several different models: fill in the first one and click Add to batch. Repeat for each model, then add them all together.
  • From an Excel sheet: click Import, then Download sample file. Fill it in, up to 1,000 rows, and choose the file. Nothing is saved until every row is right. Any mistakes are listed by row and column, so you can fix the sheet and try again.

Every unit gets its own asset tag, and the panel lists them all so you can copy them for labels. Import and adding many at once only work if you can add that part type yourself. If you can't, add units one at a time and each one becomes a Request.

Edit, report or remove a part

All three start from the ··· button at the end of the part's row. You only see Edit and Delete there if your role allows them.

Fix a mistake

Click ···, then Edit. Change what's wrong and save.

Report a broken part

1

Click ···, then Edit.

2

Under Status, choose Failed, and fill in the Failed on date.

3

Write what's wrong in Notes, for example No display output, tested in two servers. Save.

A failed part can't be picked when building a server. When it's repaired, set it back to Available.

Is the broken part inside a server?

Its status is locked while it's installed. Take it out first: open the server, click × on the part, then mark it Failed. Or raise a Swap Hardware request to replace it with a working one.

Delete a part

Click ···, then Delete. A part that is inside a server can't be deleted. The message names the server, so take the part out of it first.

Change many at once

Tick the boxes at the start of the rows. A bar appears with Change status, Move location, Set flag and Delete.

Example

20 SSDs were moved from Noida Office to Yotta Noida. On the Storage page, set Location to Noida Office, tick the 20 drives, click Move location and choose Yotta Noida.

Build a server

In BDC Inventory, a server is a list of real parts from stock. The builder only offers parts that are free and that fit, and checks each one before adding it.

1

Go to Servers and click Build Server.

2

Fill in Server Name, Serial Number (printed on the machine, and different for every server), Location, Rack and Position. If the server is taller than 1U, set Rack Units (U) before picking the position. Click Create Server. The builder opens.

3

Click Select Server Compute Platform. Pick the server model, then the version we have in stock, and click Install Platform. It brings its own motherboard and chassis.

4

Go down the list. On each row click Choose… (for example Choose CPU), or Add More for another of the same kind. Click Add next to the part you want.

5

Click Finish Setup, check the summary, and click Confirm & Save Configuration.

Example

A DL380 Gen10 with 2 CPUs, 16 sticks of 32 GB RAM and 8 SSDs. Install the HPE ProLiant DL380 Gen10 platform, then add 2 CPUs, 16 RAM sticks and 8 storage drives. Check that a network card is listed, then click Finish Setup.

Every server needs these six

Chassis, motherboard, CPU, RAM, storage and a network card. The compute platform already gives you the chassis and the motherboard.

Changing or removing the platform empties the server

Change and Remove put every part in the build back into stock. The system asks you to confirm first and lists what will be released.

Can't build servers with your role? Click Build Server anyway and fill in the same form. The button reads Submit request, and the server is created once an admin approves it. Track it under Requests.

Try a build without using real stock

If Server Compatibility is in your menu, use it as a test bench. Click New Test Build and add parts the same way as in the builder. Nothing is reserved, so you can even try parts that are already in other servers. Every part you try is recorded as fitting or not, with the reason. Test builds don't appear on the Servers page and can't be finished.

Look after a server

The Servers page has a card for every server. Use the search box and the All Status list at the top to find one. Servers that sit in a blade enclosure, such as a Dell FX2s, are grouped under it as Bay 1, Bay 2 and so on.

Record IP addresses

Click the pencil and scroll to IP addresses. Click Add IP, type the address (for example 10.0.4.12), choose Private or Public, add a label if it helps (for example iDRAC), then click Save IPs. This works even after the server is finalized.

Change a server's status

Click the pencil. Under Status, choose from Move to, add a reason if it's useful, and click Change status. The list only shows the moves your role allows. If the one you need isn't there, raise a Change Server Status request.

Need to swap a part in a finalized server? Change its status to Building or Maintenance first. The Move to list shows which moves are possible from where it is now. If yours isn't there, ask for it with a request.

Move a server to another rack

Raise a Move Server request with the new location, rack and U position. Every part inside the server moves with it.

Delete a server

Click the bin on its card. A server can only be deleted once all its parts are removed. If any are left, you see a message such as "This server still has 2 components installed (1 CPU, 1 motherboard). Remove all components from the server before deleting it."

When parts don't fit

Every time you add a part, the system checks it against everything already in the server. If it doesn't fit, it tells you why. Problems in red stop the part being added. Amber warnings mean it will work, but check first. Many messages also suggest what would fit instead.

The message saysIn plain wordsWhat to do
CPU socket LGA3647 incompatible with motherboard socket SP3The processor doesn't physically fit this board.Pick a CPU with the same socket as the board.
CPU limit exceeded: motherboard supports maximum 1 CPUsThe board only has room for one CPU.Use one CPU, or a board with two sockets.
Multi-socket configurations require the same CPU modelTwo CPUs in one server must be exactly the same model.Change one so both match.
… is not a CPU generation this motherboard supportsIt fits the socket, but the board can't run this generation.Pick a CPU the board supports.
SFP type QSFP+ not compatible with NIC port type SFP+The module is the wrong shape for the network port.Use the module type the port takes.
Storage form factor (2.5-inch) not supported by caddyThe drive tray is a different size from the drive.Use a caddy made for that drive size.
ECC memory used with non-ECC motherboard (warning)It works, but the memory's error protection is switched off.Fine for a test machine. Usually wrong for a live server.
M.2/U.2 storage does not require caddy (warning)This drive doesn't need a tray.Remove the caddy.
Read every reason, not just the first

A part can fail more than one check. For example, an Intel CPU added to a board that already has an AMD CPU gets three messages at once: wrong socket, too many CPUs, and different models. Fixing only the first still leaves it blocked.

Adding an SFP module? The system first asks which network card it plugs into.

Requests

A Request asks for work to be done. It moves through steps, and an admin approves it. For most request types, once approved, the system makes the change itself and records it as done by you.

Raise a request

1

Go to Requests and click New request.

2

Choose the Request type (see the table below) and a Priority: Low, Medium, High or Urgent.

3

Fill in the boxes that appear. They change with the type, and are usually the server, the part type and the model.

4

The Title fills itself in from your choices. Change it if you like, and add a Description if it helps the approver.

5

Click Create request. It gets a number like TKT-20261008-0012.

Example

Server 10U 11U - HPE ProLiant DL380 Gen10 needs one more SSD. Choose Install Hardware, pick that server, set Component type to Storage, pick the model and click Create request.

The form checks real stock while you fill it in. If we have no free unit of that model, it says We have none of these free and offers to raise the stock record first. If the part is at a different site from the server, it offers a Hardware Handover and asks who is carrying it.

Follow your request

The Requests page has three tabs at the top:

  • My queue: requests waiting on you or your team right now.
  • Created by me: requests you raised, and any request where one of the steps is yours.
  • All: every request. You only see this tab if your role allows it.

Click a request to see its steps, who has it now, and everything that happened. Use the search box and the Status, Priority and Type lists to narrow things down.

In progress→ Completed or Rejected Cancelled

Rejected means the approver said no, and their reason is shown. Cancelled means it was withdrawn. Neither can be restarted, so raise a new request if it's still needed.

"Last approval rolled back"

Approval was tried, something blocked it, and nothing was changed. A red box on the request says why, for example a serial number that already belongs to another unit. Once the cause is fixed, the admin can approve again.

Blocked or frozen

The request is waiting for another request to finish first, such as adding the part to stock. The lock message names that request. It moves on by itself once the other one is done.

Work on a step

Some steps are given to a team, such as Technician. When one reaches your team, it shows in My queue and on the bell.

1

Open the request from My queue.

2

Click Accept step so your team knows you have it.

3

Do the work, then write a short note on what you did.

4

Click Complete & advance. The request moves to the next step.

Steps called Admin Approval are done by admins, so you won't be asked to act on them.

Carrying hardware to another site

If a Hardware Handover names you as the person carrying the part, a step comes to you after approval. When the part has arrived, open the request and complete your step. Only you can confirm it, and that closes the request.

Notifications

The bell at the top tells you when a request needs you or your team, when a step is passed to you, and when a request you raised is completed, rejected or cancelled. You're never told about something you did yourself. Click a notification to open the request.

Tick Email or Teams under Also send to to get the same message there. A box you can't tick means that channel isn't set up for your account yet.

Something's not working

Click a question to see the answer.

I was signed out

Sign-ins don't last forever. Even with Keep me signed in ticked, you may be asked to sign in again after a day or after closing the browser. Anything you hadn't saved is lost, so save long forms as you go.

A button is missing, or I can't edit something

Your role doesn't include that change. Raise a Request for it instead. See Which request type to choose.

The model I need isn't in the list

It isn't in our hardware catalogue yet. Ask an admin to add it. Don't pick a similar model.

I can't save a part: Site is required

Choose the site the part is at. If the site isn't in the list, ask someone who manages Locations to add it.

I can't delete a part, or can't mark it Failed

It's inside a server. Open that server, take the part out with ×, then try again.

A part won't go into my server

Read every reason shown, not just the first. Then pick from the list the builder offers, because it only shows parts that fit. See When parts don't fit.

The list of parts to pick from is empty

No free unit fits this server. Check the part's page under the Available tab. If there are none, they need adding to stock first.

I can't remove the motherboard or chassis

They came with the compute platform and are locked to it. To change them, change or remove the platform. Remember this puts every part in the server back into stock.

I can't add or remove parts in a server

Parts can only change while the server is in Draft, Building or Maintenance. Change its status first, or raise a Change Server Status request.

I finalized a server by mistake

Click the pencil on its card and move it back to Building. If your role can't, raise a Change Server Status request.

I can't delete a server

It still has parts in it. Open it with Configure, remove every part, then delete it.

My request says "Last approval rolled back"

Nothing was changed. The red box on the request says why. Fix that, or tell the approver, and it can be approved again.

My request is frozen

It's waiting for another request to finish first. The lock message names it. Open that one to see where it's stuck.

My test build has disappeared

Test builds live on the Server Compatibility page, not on Servers. Look for it there.

The numbers look wrong

Click Refresh at the top of the page. If they still look wrong, open the server's history (the clock icon on its card) to see what changed.
